# 码途｜项目展示

中文编程阅读学习 App，使用 JavaScript、HTML、CSS 和 Capacitor。当前课程版提供路线与章节、代码讲解、知识搜索和本地学习进度。

## 可讲解的工程问题

- 课程内容和页面逻辑如何分离。
- 阅读进度如何保存和恢复。
- Web 课程资源如何筛选并打包进 Android。

## 运行

安装依赖：`npm ci`。预览：`npm run serve`。Android：`npm run sync` 后在 Android 工程构建。
